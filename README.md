<h1 align="center">Coin Master 活動道具能量換算器</h1>

<p align="center">
  把剩餘的活動道具換算成能量，加總後預估你下一週會被分到哪一組。<br>
  支援 中文 / English / Tiếng Việt / 日本語 / 한국어 / ไทย / Bahasa Indonesia / Español / Português
</p>

## 功能

- **三步驟流程**：① 填基礎能量 → ② 填剩餘道具 → ③ 看預估分組
- **道具換算**：每個道具格下方即時顯示換算後的能量，各區塊顯示小計
- **總能量計算**：基本能量 + 額外能量 + 道具換算能量，並以比例條顯示能量來源
- **分組預估**：依總能量比對分組區間，顯示下一週預估分組與「距離下一組還差多少」
- **分組對照表**：列出所有分組區間，目前所在組別會被標亮
- **多語系**：右上角切換中文、英文、越南文、日文、韓文、泰文、印尼文、西班牙文、葡萄牙文
- **手機友善**：手機版底部固定顯示總能量與預估分組，可「加入主畫面」當成 App 使用

## 使用方式

純靜態網頁，不需要安裝或建置：

1. 直接用瀏覽器開啟 `index.html`，或部署到 GitHub Pages
2. 填入基本能量與額外能量
3. 輸入剩餘的活動道具數量，結果即時顯示（桌機在右側、手機在底部結果列）

### 加入主畫面

- **iPhone（Safari）**：分享 → 加入主畫面
- **Android（Chrome）**：選單 → 加到主畫面 / 安裝應用程式

## 專案結構

```
├── index.html             # 主頁面（HTML / CSS / JS 都在這裡）
├── manifest.webmanifest   # PWA 設定（名稱、圖示、主題色）
└── images/
    ├── icon.svg           # App 圖示（向量原檔）
    ├── icon-192.png       # Android / PWA 圖示
    ├── icon-512.png       # Android / PWA 圖示
    ├── apple-touch-icon.png  # iOS 主畫面圖示
    └── *.png              # 各道具圖示
```

## 修改比例或分組

- 換算比例 / 新增道具：修改 `index.html` 中的 `items` 陣列（`mul` = 1 個換幾點能量、`div` = 幾個換 1 點能量），道具欄位會自動產生
- 分組區間：修改 `index.html` 中的 `groupRows` 陣列（`rangeLabel` / `min` / `max`）
- 詳細說明見 [CLAUDE.md](CLAUDE.md)
